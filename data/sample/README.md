# Interface examples only

These fixtures are synthetic illustrations, not solver output or observed data. Solar power 150 kW and bus voltage 12.47 kV are illustrative values based on provisional assumptions; they are not validated solved measurements. Time and identifiers are placeholders.

The JSON and publisher CSV contain the same grouped device message. The CSV measurements cell is a JSON string. Attack labels live in separate ground-truth records, not the message. The physical CSV contains only a header because no solved measurements have been validated yet. See DATA_SCHEMA.md for conversions and message/measurement row granularity.
